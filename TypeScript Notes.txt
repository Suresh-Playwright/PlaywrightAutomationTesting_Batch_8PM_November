What is TypeScript ?

Have you heard about JavaScript ?

JavaScript is a programming language used to develop interactive web application
We can use JavaScript for forntend development , backend development , and automation
testing.

But In JavaScript has one limitation . It is dynamically Typed .

What does dynamically typed mean ?

It means JavaScript does not required us to explicitly declare the datatype of a variable.


let employeeName= "Suresh";
employeeName= 100;
console.log(employeeName);

JavaScript allows us to assign a number to a  variable that previously contained a string.

Now Imagine we are developing a large automation framework with hundered of test cases.

Acciedently assign the wrong data type can create unexpected problems.

This is where TypeScript Comes into the picture.



TypeScript is a programming language developed by Microsoft. It is a superset of JavaScript that adds
 static typing and other development features.


let employeeName: string= "Suresh";
employeeName= 100; 

// Type 'number' is not assignable to type string
console.log(employeeName);

Variables In TypeScript :
-------------------------

A variable is a container used to store a data in a program.

For example , Imagine you want to store a student's name , age , salary , and marks, We use
Variables to store these values.

let studentName1 : string = "Suresh";
let age : number = 27;
let salary : number = 85000;
let isTrainer : boolean = true;

console.log(studentName1)
console.log(age)
console.log(salary)
console.log(isTrainer)



Types of Variables Declarations In TypeScript:
------------------------------------------------


1. var -- Function Scoped
2. let - Block Scoped
3. const - Block Scoped


Var : 

1. We can declare a variable usng var.
2. We can reassign its value
3. We can redeclare it in the same Scope
4. It is Function scoped not block scoped.

var employeeName : string = "Suresh";

console.log(employeeName)

employeeName= "Rahul";
console.log(employeeName)


let :

1. We can declare a variable using let.
2. We can re-assign values
3. We cannot redeclare in the same scoped
4. It is block scoped


let empName : string = "Suresh";



console.log(empName)

empName="Rahul";

console.log(empName)



const :

1. We declare constants using const.
2. We cannot reassign the variable
3. We cannot redeclare it in the same scope
4. It is block scope
5. It must be intilized during Declarations
